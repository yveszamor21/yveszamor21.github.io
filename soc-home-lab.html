03 / Evidence checklist

What each proof upload must show

01 — Setup

Screenshot: operating system and SSH status. Caption: environment, command used, result, date.

02 — Baseline

Screenshot: network configuration and log locations, with private information removed.

03 — Event

Screenshot: a reproducible, authorized failed-login event with timestamp and context.

04 — Detection

Screenshot: Python alert output paired with matching sanitized log evidence.

05 — Investigation

Short report: alert, timeline, evidence, analysis, limitations and recommended next step.

06 — Reflection

Explain what worked, what did not, false positives and planned improvements.

04 / Upload workflow

How to publish your evidence

Use the matching evidence guide. Upload redacted images under assets/images/soc-lab/ and reports under evidence/soc-lab/. Add a date, clear caption, objective, commands used and a conclusion for each. Once proof is uploaded, replace the corresponding “Pending” text with a link and verified outcome.

Privacy: never upload passwords, tokens, personal records, internal employer information, or sensitive network details.
